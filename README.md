# DEMO-DATA

## test_pii.csv
100 rows of **synthetic** PII for DLP testing. All names, addresses, emails (`example.com`), and phones (555-01xx) are fake; card numbers are public test PANs; SSNs are randomly generated in valid format and not tied to real people.

## Other formats
The same 100 records in `test_pii.json`, `test_pii.txt`, `test_pii.xlsx`, `test_pii.docx`, and `test_pii.pdf`, for testing DLP inspection across file types.
